# 7记账 v1.3.0

本版重写截图识别管线，并新增 iOS 27 系统授权自动识屏会话。继续使用原生液态玻璃界面。

- **自动识屏会话（实验性）**：在“我的 → 自动记账”通过系统界面开启；会话期间自动识别稳定显示的微信/支付宝成功支付页，无需每笔按键或截屏。基于 ScreenCaptureKit，配置 `screen-capture` 后台模式、权限用途说明及停止入口，不保存视频、不上传画面、不采集麦克风或摄像头。
- **OCR 与字段解析**：修正图片方向；按标签坐标复读长商户及商品；处理多行值、孤立数字续行、下划线与减号；分别保存商户和商品。实付优先，支付时间不取状态栏时钟，银行名不再覆盖支付平台来源。
- **减少错账**：移除截图失败时读取旧剪贴板的兜底；退款不再回退为消费；缺失或冲突信息标待确认。按交易单号区分同店、同金额的连续消费；同一单号重复识别不重复扣余额。兼容旧账本。
- **截图辅助入口**：可配置关闭微信/支付宝时自动识别90秒内的新截图；仍需先手动截屏，并提前授权相册。

验证：145项解析、版式、去重、余额、同步及识屏门控检查通过。8张真实 HEIC 微信账单原图逐字段核对，8/8图片、72/72字段全部匹配，包括金额、分类、来源、账户、渠道、支付时间、商户、商品及资金流向。原图和私人测试报告未上传。

**验证边界**：图片验收运行于本机 Apple Vision，与 App 复用相同识别代码；不是 iPhone 端到端测试。8张样本均为微信账单，不能据此承诺支付宝或任意截图100%准确。分类按可见信息和现有规则验收。

自动识屏已通过 iOS 编译、后台配置及弱链接检查，**安装签名权限、系统授权、跨 App 后台运行、锁屏行为和耗电仍需真机验证**。会话必须由用户明确开启，系统共享状态可见，停止后不会自动重启；它不是绕过系统限制的永久静默监听。如果系统提示安装签名缺少屏幕采集权限，需使用支持该能力的签名；单纯反复授权或 ad-hoc 签名不能补齐权限。

附件 `7jizhang.ipa` 是 ad-hoc 签名构建，需用自己的开发者证书或支持的侧载工具重新签名；主程序与灵动岛扩展都需要签名。最低 iOS 26，自动识屏需要 iOS 27。本次未提供未验证可导入的快捷指令附件，请直接在 iPhone 动作库搜索“7记账”添加动作。
