# 7记账 v1.4.0

本版支持收入、退款和自定义分类，并精简记账方式。继续使用 iOS 液态玻璃界面，最低 iOS 26。

- **商户完整显示**：账目详情的商户编辑框、顶部名称、商品和账目列表支持换行；名称使用标签旁的剩余宽度，不再限制在右侧单行。旧 OCR 原文中存在明确公司后缀续行时，升级可恢复完整名称，不改变账目金额。
- **自动记账只保留银行短信**：移除银行邮件、自动剪贴板、截屏后退出自动记账和实验性识屏会话。移除相关屏幕采集框架及后台配置。保留原来的手动按键截图、App 内截图和主动粘贴识别。
- **收入和退款**：银行卡入账短信可自动记录收入；微信/支付宝转账收款、红包和退款可用手动按键截图记录。消费退款单独记收入，默认分类为“退款”。App 内记一笔可选收入/支出和收支账户，统计分别计算收入、支出及结余。
- **两种入口都能识别新卡**：短信和按键截图在新增、合并及判重路径中登记银行和卡尾号，启动时从已有账目补登记。不同银行的同尾号卡不混合；账单只显示末四位时，不推测完整卡号。
- **自定义分类**：可添加和删除收入/支出分类。删除不改变历史名称与统计，同步保留删除记录，防止旧备份复活已删分类。入口位于“我的”、记一笔分类区及账目详情分类菜单。
- **加强去重**：原消费和同单号退款分开记录；重复识别不重复增加/扣减余额；同店同金额但不同单号、明确时间不同的交易保留两笔；取消“商户前四字一样就合并”的判断。同单号再次识别可以补全信息和新卡，仍只保留一笔。

验证：181项解析、收入/退款、余额、去重、新卡、历史兼容、分类删除与同步回归通过。原8张真实微信 HEIC 支出原图仍保持8/8图片、72/72字段匹配。收入、红包和退款使用模拟文本回归，未获得对应真实原图；不能据此承诺所有收款截图100%准确。原图及私人报告未公开。

**手动按键请使用两个动作**：“截屏”→“7记账 · 识别截图记账”，截图参数选择上一步截屏结果。不再增加系统“从图像中提取文本”步骤，确保使用 App 内的完整 OCR 管线。以前已在手机创建的邮件、退出 App 或剪贴板自动化需在快捷指令中自行删除，App 无权替你删除系统个人自动化。

**安装包**：改用基础 ZIP Stored 格式，包会更大；逐项校验 ZIP 本地头、压缩方法、长度、CRC、Bundle Identifier、主程序与扩展可执行文件，并做严格签名校验。针对之前 SideStore 的“Archive appears to be corrupt”，旧版与新版原始包都通过本机 CRC 检查，未拿到设备上的失败文件，根因尚未确认；新包也尚未在用户设备 SideStore 上复测，不能冒称真机安装已解决。

从 Assets 下载 `7jizhang.ipa`，不要导入 Source code.zip。IPA 为 ad-hoc 构建，仍需 SideStore 或自己的开发者证书重签，主 App 与灵动岛扩展均需签名。iPhone 上的最终布局和安装仍需设备验收。
