# 7记账 v1.4.10

修正手动按键记账引导。推荐快捷指令仅用「截屏」→「7记账 · 识别截图记账」，把第二步的「截图」参数连接到截屏结果。图片直接传给 App 内置 OCR，无需存入相册或经过剪贴板。若系统不允许连接图片参数，可改用「截屏」→「从图像中提取文本」→「7记账 · 解析账单文本记账」，仍可一键触发；该备用路径使用系统 OCR，可能丢失账单版面信息，记完需核对结果。

“我的 → 自动记账 / 手动记账”及 README 已同步更新。首次打开 App 不再主动请求相册权限。截图入口增加收到图片大小及失败原因日志，方便定位快捷指令参数是否接错。账单识别算法沿用此前通过 8/8 张微信原图、72/72 字段的 App 内 Vision 管线；本版未在 iPhone 真机验证快捷指令图片参数是否可连接，因此提供上述备用路径。181/181 项解析与去重回归通过，IPA 本地签名和 ZIP 校验通过。
