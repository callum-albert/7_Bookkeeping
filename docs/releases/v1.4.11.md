# 7记账 v1.4.11

手动按键记账提供两种直接传截图的快捷指令方式。优先使用「截屏」→「7记账 · 识别截图记账」，把截图结果接到图片参数。如果系统只显示文件选择器，可用「截屏」→「Base64 编码」→「7记账 · 用编码截图记账」，把编码结果接到字符串参数。后一种方式传递的是原始图片字节，App 解码为图片后运行相同的 Vision OCR；快捷指令不做文字识别，也不写入相册。两种快捷指令都可绑定操作按钮，一按触发。

“我的 → 手动记账”与说明文档已同步更新。截图入口增加参数诊断日志，便于确认快捷指令是否真正交付了图片。本地构建与 IPA 校验通过；实际 iPhone 上的快捷指令参数连接和后台运行仍需设备验证。
