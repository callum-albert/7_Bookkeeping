# v1.5.1 — 简化余额入口，取消账单确认

- 余额页移除固定的「余额与账单核对」及「本人账户转账 / 提现 / 充值」选项。
- 仅在余额与账单存在差异、负余额或资金流动未匹配到账户时显示提示，用户可从提示进入核对、修正余额及处理资金流动。
- 保留明确提现/充值的自动两端余额调整，以及账目增删改时的余额更新。
- 取消账单确认机制：移除首页待确认数量、账单行标签、待确认列表、详情确认按钮和识别成功后的核对催促。
- 升级时清除历史账单中的确认状态；导入旧备份不会恢复确认任务，不改动账单金额或账户余额。
- 保留 OCR 内部置信度和重试逻辑，仅用于改善识别，不要求用户逐笔确认。账单仍可直接编辑或删除。
